# Packfolio V1.1

Safari-first Packlisten-Prototyp.

## Veröffentlichung
`index.html` in das eigene GitHub-Repository `packfolio` hochladen und GitHub Pages für den Branch `main` aktivieren.

## Funktionen
Startseite und Reisenverwaltung; getrennte kategorisierte Packliste; Lexikon; kombinierbare Vorlagen; Mengen; zuletzt verwendete Gegenstände; Eingabe mit `und`-Trennung; JSON-Backup.

## Hinweise
Die Mikrofonaufnahme ist bewusst deaktiviert, bis die Safari-Problematik geklärt ist. iPhone-Tastaturdiktat im Eingabefeld kann verwendet werden. Daten werden nur lokal im Safari-Speicher gespeichert. Vor dem Wechsel von der alten Version ein Backup exportieren. Der neue Prototyp übernimmt alte Browserdaten nicht automatisch. Keine Synchronisierung mit Supabase.
