# Packfolio V1.4

Baut auf dem originalen Packfolio V1.3 auf.

## Neu
- Gegenstandslexikon um situative Ausrüstung für 17 Anlassgruppen erweitert.
- 18 kombinierbare Anlass-Bausteine ergänzt, inklusive Festlicher Anlass und Gala / Black Tie.
- Abgleich von neuen Gegenständen gegen vorhandene Namen und Aliasnamen.
- Archivierte Einträge werden beim Erstellen und Hinzufügen nicht automatisch reaktiviert.
- Vorhandene Reisen, Lernfunktion, Kategorien, Fortschritt, JSON-Import/-Export und Hinzufügen bleiben erhalten.

## Hinweise
- Die Anlass-Bausteine sind Vorschläge, keine vollständigen oder verbindlichen Listen.
- Speicher-Schlüssel `packfolio-v11` bleibt unverändert; bestehende Safari-Daten werden nicht absichtlich zurückgesetzt.
- JSON-Sicherungen vor dem Update ausdrücklich empfohlen.
- Rückreise-Checkliste, PaperPeace, echte Mikrofonaufnahme und Cloud-Sync bleiben für spätere Versionen.
- Auf iPhone-Safari noch praktisch zu testen.
