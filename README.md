# Packfolio 1.7.4

Packfolio ist eine mobiloptimierte Packlisten-Web-App. Dieses Paket ist für GitHub Pages vorbereitet.

## Dateien

- `index.html` – vollständige Packfolio-Web-App mit eingebetteten Kategorienillustrationen.
- `README.md` – diese Hinweise zur Version und Installation.

## Änderungen in 1.7.4

- 14 farbige Kategorienillustrationen als eingebettete WebP-Grafiken (128 × 128 Pixel, transparenter Hintergrund).
- Kleidung & Schuhe: T-Shirt und vollständiger Schuh.
- Fahrrad & Outdoor: Fahrrad mit Berglandschaft.
- Abreiseaufgaben: Checkliste statt Koffer.
- Zahnrad oben rechts als Lucide-ähnliches SVG statt Emoji.
- Aufbauend auf 1.7.3, einschließlich der Korrektur für „Gegenstand hinzufügen“.

## Installation auf GitHub Pages

1. Vorher in Packfolio eine JSON-Sicherung der Daten exportieren.
2. `index.html` im bestehenden GitHub-Repository durch die gleichnamige Datei aus diesem Paket ersetzen.
3. `README.md` ebenfalls ins Repository übernehmen bzw. aktualisieren.
4. Änderungen committen und nach der Veröffentlichung die Website neu laden.

## Datenspeicherung

Packfolio speichert Daten lokal im Browser. Beim Aktualisieren derselben GitHub-Pages-Adresse im selben Browser bleiben sie grundsätzlich erhalten. Eine lokale HTML-Datei oder eine andere Domain kann einen anderen Speicherbereich verwenden. Daher vor Updates immer eine JSON-Sicherung erstellen.

## Prüfhinweis

Dieses Release enthält eine einzelne HTML-Anwendung ohne separate Bilddateien. Die Darstellung und Bedienung auf dem iPhone sollten nach dem Deployment geprüft werden.
